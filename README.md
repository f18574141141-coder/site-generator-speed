A faster drop-in for makefun-site 1.0.0: `solve.js` builds a static site exactly as makefun-site does — same pages, index and tag pages, build report and static files, byte for byte — in about a third of the CPU time. It renders Markdown in a single pass with batched escaping, memoises slugs, and renders templates into one shared output buffer.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
